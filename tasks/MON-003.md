
- [ ] **3.2** `lib/analytics/mixpanel.ts` — SDK 초기화 + 헬퍼 함수
  ```typescript
  import mixpanel from 'mixpanel-browser';
  
  const MIXPANEL_TOKEN = process.env.NEXT_PUBLIC_MIXPANEL_TOKEN;
  
  export function initMixpanel(): void {
    if (!MIXPANEL_TOKEN || typeof window === 'undefined') return;
    mixpanel.init(MIXPANEL_TOKEN, {
      debug: process.env.NODE_ENV !== 'production',
      track_pageview: false,
      persistence: 'localStorage',
      ip: false,
    });
  }
  
  export function trackDiagnosisStarted(diagnosisId: string): void {
    if (!MIXPANEL_TOKEN) return;
    mixpanel.track('diagnosis_started', {
      diagnosis_id: diagnosisId,
      timestamp: Date.now(),
    });
  }
  
  export function trackDiagnosisCompleted(diagnosisId: string): void {
    if (!MIXPANEL_TOKEN) return;
    mixpanel.track('diagnosis_completed', {
      diagnosis_id: diagnosisId,
      timestamp: Date.now(),
    });
  }
  ```

## 4. ✅ Acceptance Criteria (GWT)

**AC-1 (정상):** 진단 시작 이벤트 추적
- **Given** 사용자가 `/diagnosis` 페이지에서 진단 시작 버튼 클릭
- **When** `trackDiagnosisStarted(diagnosisId)` 호출
- **Then** Mixpanel `diagnosis_started` 이벤트가 `diagnosis_id`, `timestamp` 속성 포함하여 기록

**AC-2 (정상):** 진단 완료 이벤트 추적
- **Given** 사용자가 진단 결과 페이지 `/diagnosis/result/[id]` 도달
- **When** 컴포넌트 마운트 (한 번만)
- **Then** Mixpanel `diagnosis_completed` 이벤트가 `diagnosis_id`, `timestamp` 속성 포함하여 기록

**AC-3 (성능):** Funnel p50 ≤ 10분 측정 가능
- **Given** AC-1, AC-2 이벤트가 정상 누적
- **When** Mixpanel Dashboard에서 Funnel 분석 실행
- **Then** `diagnosis_started → diagnosis_completed` 평균 시간 p50/p95 표시. REQ-NF-008 검증 가능

**AC-4 (PII 보호):** 익명 distinct_id
- **Given** 이벤트 추적 활성화
- **When** Mixpanel 이벤트 페이로드 검사
- **Then** 이메일·전화·실명 0건. `ip: false` 옵션 적용

**AC-5 (예외):** 토큰 미설정 시 noop
- **Given** `NEXT_PUBLIC_MIXPANEL_TOKEN` 환경변수 미설정 (로컬 개발)
- **When** `trackDiagnosisStarted()` 호출
- **Then** 에러 발생 X (조용히 무시). 페이지 정상 동작
