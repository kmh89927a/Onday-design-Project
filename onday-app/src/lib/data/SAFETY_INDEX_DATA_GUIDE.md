# safety-index.json 데이터 채우기 가이드 (르르용)

#57 QRY-SINGLE-001 — 수도권 66 시군구 종합 야간안전 지수.
로직·스키마는 완성됨. 서울 25구 골격 + CCTV 14구 채워짐(범죄등급 대기). **나머지 값을 채우면 끝.** 코드 수정 불필요, JSON에 값만 추가.

---

## 0. 목표

`src/lib/data/safety-index.json` 의 `entries` 배열에 **수도권 66 시군구**를 모두 채운다.
완료 검증: `npm run check:coverage` → `✅ 수도권 66 시군구 100% 커버 — 통과` 가 뜨면 끝.
(현재는 `8/66 = 12.1%` 로 실패 상태가 정상 — 채울수록 숫자가 올라감.)

## 1. 채울 항목 (행 하나당)

```json
{ "sigungu": "관악구", "region1": "서울특별시", "crimeGrade": 4, "cctvPerKm2": 136,
  "_crimeSource": "행안부2024:범죄3등급", "_cctvSource": "etoday2022:4029대÷면적29.57" }
```

| 필드 | 의미 | 어디서 | 비고 |
|---|---|---|---|
| `sigungu` | 시군구 키 | (아래 §2 키 규칙 엄수) | ★ 오타 시 매핑 실패 |
| `region1` | 광역 | "서울특별시"/"인천광역시"/"경기도" | 표시·구분용 |
| `crimeGrade` | 범죄 등급 1~5 또는 `null` | **출처 ①** 행안부 지역안전지수 | 1=안전 … 5=위험. 미수집은 `null` |
| `cctvPerKm2` | 면적당 CCTV 대수 또는 `null` | **출처 ②** CCTV수 ÷ 면적(km²) | 정수 반올림. 미수집은 `null` |
| `_crimeSource` | 범죄등급 출처 (정직성) | 어디서 가져왔는지 한 줄 | 채울 때 같이 기록 |
| `_cctvSource` | CCTV 출처 (정직성) | 어디서 가져왔는지 한 줄 | 채울 때 같이 기록 |

### ★ 단계별 채우기 (중요)
- **한 시군구가 "완성"되려면 `crimeGrade` + `cctvPerKm2` 둘 다 숫자**여야 함. 하나라도 `null` 이면 그 동네는 화면에서 "데이터 없음" 처리(no_data).
- **그래서 CCTV 먼저, 범죄등급 나중에 채워도 됨.** 이미 CCTV 14구는 채워져 있고(`crimeGrade: null` 상태) — 범죄등급만 채우면 완성됨.
- 가짜값 절대 금지: 출처 없는 칸은 반드시 `null`. (지금 서울 11구가 CCTV `null` — 출처 못 찾아 비워둔 것)
- `_filled` 필드는 폐기됨. 완성 판정은 두 숫자 존재 여부로 자동.

## 2. ★ sigungu 키 규칙 (가장 중요 — 틀리면 매핑 안 됨)

코드의 `normalizeGu()` 출력과 **정확히 일치**해야 한다:

| 권역 | 규칙 | 예 |
|---|---|---|
| 서울 25 | 자치구명 그대로 (bare) | `"강남구"`, `"종로구"` |
| 인천 10 | **"인천 " 프리픽스 필수** (서울 중구 ↔ 인천 중구 충돌 방지) | `"인천 서구"`, `"인천 중구"` |
| 경기 31 | **시·군 단위** (일반구 빼기) | `"성남시"` (분당구/수정구 합침), `"고양시"`, `"김포시"` |

정확한 66개 키 목록은 `scripts/check-coverage.ts` 의 `EXPECTED` 배열에 있음 (복붙 가능).
미달 시 `check:coverage` 가 빠진 키를 정확히 출력해줌.

## 3. 출처 ① 범죄 등급 (행안부 지역안전지수)

1. **공공데이터포털 → "행정안전부_지역 안전지수 등급현황"** (`data.go.kr/data/15069240`) 엑셀 다운로드.
2. 시트에서 **"범죄" 분야** 컬럼만 사용. 시군구별 1~5등급이 이미 박혀 있음 (인구·면적 정규화 완료 — 추가 계산 불필요).
3. 해당 시군구 행의 범죄 등급 숫자를 `crimeGrade` 에 그대로 입력.
   - ⚠️ 경기 일반구(분당/수정 등)는 행안부도 "성남시" 한 줄 → 그 값을 성남시에 사용 (= 시 단위 타협, 의도된 동작).

## 4. 출처 ② CCTV 밀집도 (대/km²)

각 권역별 CCTV 총 대수를 받아 **시군구 면적(km²)으로 나눔**:

| 권역 | CCTV 출처 | 면적 출처 |
|---|---|---|
| 서울 | 서울 열린데이터광장 "자치구 연도별 CCTV 설치현황" (`OA-2734`) | 자치구 면적(위키/행안부) |
| 인천 | 공공데이터포털 "인천광역시_방범 CCTV 설치현황" (`15104287`) | 군·구 면적 |
| 경기 | 경기데이터드림 "CCTV 현황" (시군별) | 시·군 면적 |

`cctvPerKm2 = round(CCTV대수 ÷ 면적km²)`. 예: 강남구 6,495대 ÷ 39.5km² ≈ 164.
- 면적 정규화가 번거로우면 **"인구 10만명당 CCTV"로 대체해도 됨** — 단 66행 전부 같은 기준으로 통일할 것. (기준 바꾸면 `safety-index.ts` 의 `CCTV_MIN`/`CCTV_MAX` 상수도 그에 맞게 조정 필요 → 그건 클로드에게 요청.)

## 5. 현재 진척 (2026-05-31 기준)

| 구분 | 상태 |
|---|---|
| 서울 25구 골격 | ✅ JSON에 행 다 있음 |
| 서울 CCTV | 🟡 14구 채움(이투데이2022÷위키면적), 11구 `null`(광진·동대문·중랑·강북·서대문·양천·강서·영등포·서초·송파·강동) |
| 서울 범죄등급 | ❌ 25구 전부 `null` — **다음 단계** |
| 인천 10 / 경기 31 | ❌ 행 자체 없음 |

→ **완성 0/66.** 가장 빠른 다음 단계 = **서울 범죄등급 채우기**(가중치 0.7로 더 중요 + 행안부 엑셀 1파일로 25구 한 번에).
범죄등급만 채우면 CCTV 있는 14구가 즉시 "완성"됨.

## 6. 채우는 순서 (점진적 OK)

1. **서울 범죄등급 25구** (행안부 엑셀 §3) → CCTV 14구 즉시 완성.
2. **서울 CCTV 나머지 11구** (열린데이터광장 OA-2734 엑셀 §4) → 서울 25구 완성.
3. **인천 10** (자치구라 깔끔) → 행 추가.
4. **경기 31** (시 단위, 일반구 합산 주의) → 행 추가.
- 중간에 `npm run check:coverage` 돌리면 완성/미완성/CCTV만 채운 수를 알려줌.
- 서울만 완성돼도 동작함 (경기/인천 동네는 그동안 "데이터 없음" = 의도된 fallback).

## 7. 완료 확인

```bash
npm run check:coverage     # ✅ 66/66 = 100% 떠야 함
npx tsc --noEmit           # 타입 에러 0
```

## 8. 주의

- `_meta` 블록은 건드리지 말 것 (스키마 설명용).
- 서울 CCTV 14구는 **이투데이2022 기사 대수 ÷ 위키 면적**으로 계산한 값 (출처 `_cctvSource`에 기록). 행안부 OA-2734 엑셀로 받으면 더 정확 → 덮어써도 됨.
- 임계값(등급 A/B/C/D 경계, CCTV 정규화 범위)은 66행 다 채운 뒤 분포 보고 클로드가 튜닝 (C-3 합의).
- 한글 인코딩: 저장 후 깨짐 없는지 확인 (NFC).
