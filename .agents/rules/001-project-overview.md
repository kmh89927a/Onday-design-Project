# OnDay (동네궁합진단기) — Project Overview

> 본 룰은 Antigravity / Gemini CLI 환경에서 모든 작업에 자동 주입된다. cross-tool 글로벌 규칙 `AGENTS.md` 와 정합한다. 충돌 시 `AGENTS.md` 와 `docs/00_PRD_v1.1-rev.4.md`·`docs/05_SRS_v1.6.md` 가 우선한다.

## Vision

**프로젝트명:** OnDay (온데이) — "내 하루 동선 맞춤 동네 궁합 진단기"

이사를 앞둔 3040 맞벌이 부부·긴급 이사자·반복 이사자가 **두 사람의 출퇴근 동선을 동시에 만족하는 동네를 찾을 도구가 시장에 존재하지 않아** 발생하는 주거 미스매치, 탐색 비용 낭비, 부부 합의 실패 70%, 심리적 고립감 문제를 해결한다.

## Domain

프롭테크 × 하이퍼로컬 × 초개인화 큐레이션 (3각 교차점)

## Personas (MVP 타겟)

- **C-01 맞벌이 부부** — 두 동선 교차 + 배우자 합의
- **C-02 맹모삼천지교** — 학군 + 광역버스 착석 통합
- **C-03 긴급 이사자** — 데드라인 급매 필터링 (WTP 가장 높음)
- **C-04 반복 이사자** — 입력값 저장·재탐색
- **A-01 이직 후 이사자** — 싱글 모드 간소화

## Core Features (MVP Must)

1. **두 동선 교차 진단** — 주소 2개 → 교집합 동네 지도 시각화 + 출퇴근 시간
2. **배우자 공유 링크** — URL 공유 + 무료 미리보기 1곳 + 데이터 출처 배지
3. **데드라인 모드** — 이사 기한 → 급매 우선 + 계약 역산 타임라인
4. **싱글 모드** — 학군 숨김 + 야간 치안·라이프스타일 레이어
5. **간이 저장·불러오기** — best effort 자동 저장 (Rev 1.5 축소)

## KPI

- **북극성:** 진단 완료 수 / 주 (Closed Beta 50건/주 → Open Beta 200건/주)
- **보조:** WTP 설문 응답률 ≥ 30%, 배우자 공유 링크 클릭률 ≥ 40%, D+7 리텐션 ≥ 25%, NPS ≥ 50

## Project Philosophy

- **단순 우선:** 1인 개발자(3년차 IT기획 퍼블리셔 + 초급 SW) MVP 컨텍스트. 불필요한 추상화·디자인 패턴 자제.
- **단일 풀스택:** Next.js 단일 프레임워크로 모든 것 처리. 마이크로서비스·별도 백엔드 서버 금지.
- **공식 권장 자산 우선:** shadcn/ui, Vercel AI SDK, Supabase Auth 같이 검증된 권장 자산 활용.
- **PRD/SRS 가 SSoT:** 본 룰과 PRD/SRS 가 충돌하면 PRD/SRS 가 우선.

## Out of Scope (MVP) — 자동 코드 생성 금지

- 매물 중개 / 계약 체결 (라이선스 필요)
- 결제 시스템 (PG 연동, 웹훅, 구독) — WTP 는 사전 설문으로 측정
- 지방(비수도권) 커버리지
- 학원 셔틀 종점 DB
- 복수 목적지 모드 (5개 거점)
- 이전 탐색 비교 뷰 / 시나리오 3개 비교 / 행정동 변경 감지
